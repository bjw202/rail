## 쉬운 말 요약

1. 리더가 `/rail`을 칠 때마다 읽는 "매번 하는 일" 1번을 다섯 갈래로 고쳤다. 다섯 갈래는 급한 장애, 버그, 작은 수정, 기능·동작 바꾸기, 질문만이다. 주인이 읽는 한 쪽 사용법에는 "이럴 땐 이렇게 말하세요" 표를 넣었다. 실행 코드 줄 수는 그대로이다(3,500).
2. 작은 CLI 예제로 M0를 닫은 뒤, 주인 대역으로 여섯 말을 하나씩 던졌다. 두 판 모두 여섯 말 가운데 다섯은 기대한 갈래와 첫 행동이 맞았다.
3. 첫 판에서는 "지금 실행하면 바로 죽어요"(급한 장애)에 리더가 되돌리기를 말하지 않고 재현부터 하다가 되물었다. 그래서 문장을 "재현·원인 찾기보다 먼저 되돌리자고 한다"로 고쳤다. 둘째 판에서는 리더가 되돌리기를 먼저 따져 보았지만, 최근 커밋이 코드를 건드리지 않아 되돌려도 달라질 것이 없다고 보고 제안하지 않은 채 되물었다. 이 판단은 tiny 예제에서는 맞는 말이지만, 지시서가 기대한 "직전 커밋으로 되돌리기 제안"과는 다르다. 그래서 표에는 "부분 맞음"으로 적었다.
4. 질문만 한 경우("반말 모드도 되나요?")에는 두 판 모두 step도 기획서 고침도 없이 답·추천과 "지금 / 나중에 / 안 함"만 물었다. 기능 둘을 한꺼번에 말한 경우에는 두 판 모두 마일스톤 두 개(M1 반말, M2 영어)로 나누자고 했다.

## 리허설 표

리더 대역은 `claude -p "/rail <주인 말>"`(Claude Code 2.1.332)로 돌렸고, Codex는 쓰지 않았다. 말마다 `base` 태그에서 새로 복제한 사본에서 돌렸으므로, 앞 말이 남긴 상태는 다음 말에 이어지지 않는다(git으로 되돌린 것과 같은 효과). 장면 S1에는 빈 이름 이야기가 없고, "## 나중에"에 "이름 없이 치면 undefined" 한 줄이 있다.
